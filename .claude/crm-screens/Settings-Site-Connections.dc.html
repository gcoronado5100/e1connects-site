Connectors

Website connectors identify where leads and contacts come from: the Source column and the Site filters. External services (e.g. n8n) authenticate with an API key.

How does it work?

Website connectors are linked to their WordPress site with the E1D Connection plugin (v2): choose "Connect WordPress", paste the one-time code in the plugin and the site signs every lead it sends. No API keys to copy. For external services, create an API key and send it in the X-API-Key header.

Filters
Websites

Website connectors. They appear in the Source column and in the Leads, Clients and Conversations filters.
